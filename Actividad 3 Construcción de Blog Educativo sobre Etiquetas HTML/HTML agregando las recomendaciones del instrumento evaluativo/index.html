HTML desde lo básico

Este es un blog para saber un poco sobre HTML y sus etiquetas. Nada muy avanzado, solo lo esencial para que entiendas para qué sirve cada una.

¿Qué es HTML? Es el lenguaje que le dice al navegador cómo estructurar una página web: dónde va el título, los párrafos, las imágenes, los enlaces, las listas… básicamente el esqueleto de casi todo lo que ves en internet.

Aquí vas a encontrar etiquetas explicadas con ejemplos prácticos, definiciones claras y las cosas que realmente vale la pena tener en cuenta.

Etiquetas de Estructura Semántica

<header>

Definición

Define la cabecera de una página o sección. Generalmente contiene el logotipo, título principal y navegación.

Sintaxis

<header> <h1>Mi Sitio Web</h1> <nav>...</nav> </header>

Demostración visual

[HEADER] — Logotipo · Navegación · Título

Buenas prácticas

  • No anidar <header> dentro de otro <header>.
  • Usarlo una sola vez por página (o por <article> / <section>).
  • Incluir la navegación principal aquí.
<nav>

Definición

Agrupa los enlaces de navegación principal del sitio. Ayuda a lectores de pantalla a identificar el menú.

Sintaxis

<nav> <a href="#inicio">Inicio</a> <a href="#sobre">Sobre mí</a> <a href="#contacto">Contacto</a> </nav>

Demostración visual

Inicio Sobre mí Contacto

Buenas prácticas

  • Solo para bloques de navegación importantes.
  • Usar <ul> dentro para mejor accesibilidad.
<main>

Definición

Contiene el contenido principal y único de la página. Solo debe existir uno por documento HTML.

Sintaxis

<main> <article>...</article> <section>...</section> </main>

Buenas prácticas

  • Nunca repetir dentro de un mismo documento.
  • No incluir <header>, <footer> ni <nav> del sitio dentro.
<section>

Definición

Agrupa contenido temáticamente relacionado. A diferencia de <div>, tiene significado semántico.

Sintaxis

<section id="servicios"> <h2>Nuestros Servicios</h2> <p>Ofrecemos...</p> </section>

Buenas prácticas

  • Cada <section> debe tener un heading (<h2>–<h6>).
  • Si no tiene heading, usar <div> en su lugar.
<article>

Definición

Representa contenido independiente y reutilizable: entrada de blog, noticia, tarjeta de producto, comentario, etc.

Sintaxis

<article> <h2>Título del Post</h2> <p>Contenido del artículo...</p> <footer>Autor: Ana</footer> </article>

Buenas prácticas

  • El contenido debe tener sentido de forma independiente.
  • Puede contener su propio <header> y <footer>.
<aside> <footer>

Definición — <aside>

Contenido complementario pero no esencial: barra lateral, anuncios, enlaces relacionados.

Definición — <footer>

Pie de página o sección. Contiene datos de copyright, contacto, sitemap o créditos.

Sintaxis

<aside> <h3>Artículos relacionados</h3> </aside> <footer> <p>© 2025 HTMLpedia. SENA</p> </footer>

Buenas prácticas

  • <aside>: no meter contenido crítico de la página.
  • <footer>: incluir siempre info legal y de contacto.
