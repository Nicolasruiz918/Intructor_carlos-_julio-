Etiquetas de Listas

<ul> <ol> <li>

Definiciones

<ul> — Lista desordenada (viñetas).
<ol> — Lista ordenada (numerada).
<li> — Ítem de lista.

Sintaxis

<ul> <li>Manzanas</li> <li>Naranjas</li> <li>Peras</li> </ul> <ol> <li>Instalar VS Code</li> <li>Crear index.html</li> <li>Abrir en navegador</li> </ol>

Demostración visual

UL (viñetas)
  • Manzanas
  • Naranjas
  • Peras
OL (numerada)
  1. Instalar VS Code
  2. Crear index.html
  3. Abrir en navegador

Buenas prácticas

  • Usar <ol> cuando el orden importa (pasos, ranking).
  • Usar <ul> para ítems sin jerarquía de orden.
  • Nunca poner elementos que no sean <li> directamente dentro.
<dl> <dt> <dd>

Definiciones

<dl> — Lista de definiciones (glosario).
<dt> — Término a definir.
<dd> — Descripción o definición del término.

Sintaxis

<dl> <dt>HTML</dt> <dd>HyperText Markup Language</dd> <dt>CSS</dt> <dd>Cascading Style Sheets</dd> </dl>

Buenas prácticas

  • Ideal para glosarios, metadatos, FAQs.
  • Un <dt> puede tener múltiples <dd>.
