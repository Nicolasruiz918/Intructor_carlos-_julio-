Etiquetas de Tablas

<table> <thead> <tbody> <tr> <th> <td>

Definiciones

<table> — Contenedor principal de la tabla.
<thead> — Sección de encabezado de columnas.
<tbody> — Cuerpo con los datos.
<tr> — Fila (Table Row).
<th> — Celda de encabezado (negrita, centrada).
<td> — Celda de dato.

Sintaxis

<table> <thead> <tr> <th>Etiqueta</th> <th>Uso</th> </tr> </thead> <tbody> <tr> <td><header></td> <td>Cabecera</td> </tr> </tbody> </table>

Buenas prácticas

  • Tablas solo para datos tabulares, nunca para layout.
  • Usar scope="col" en <th> para accesibilidad.
  • Agregar <caption> para describir la tabla.
