Etiquetas de Texto y Contenido

<h1> – <h6>

Definición

Encabezados jerárquicos. <h1> es el más importante y debe aparecer una sola vez por página.

Sintaxis

<h1>Título Principal</h1> <h2>Subtítulo</h2> <h3>Sección</h3>

Demostración visual

H1 — Título Principal

H2 — Subtítulo

H3 — Sección

Buenas prácticas

  • No saltar niveles (ej: de H1 a H4 directamente).
  • Un solo <h1> por página para SEO.
<p> <span> <strong> <em>

Definiciones

<p> — Párrafo de texto. Elemento de bloque.
<span> — Contenedor en línea sin semántica propia.
<strong> — Texto importante (negrita semántica).
<em> — Énfasis (cursiva semántica).

Sintaxis

<p>El <strong>HTML</strong> es el <em>lenguaje base</em> de la web. Usa <span style="color:red">span</span> para estilos en línea.</p>

Demostración visual

El HTML es el lenguaje base de la web. Usa span para estilos en línea.

Buenas prácticas

  • Usar <strong> / <em> con significado, no solo para estilo visual.
  • Para estilos visuales puros, preferir CSS sobre <b> / <i>.
<br> <hr>

Definiciones

<br> — Salto de línea dentro de un párrafo (dirección, poesía).
<hr> — Separador horizontal temático entre secciones.

Sintaxis

<p>Calle 45 # 12-30<br> Bogotá, Colombia</p> <hr> <p>Nueva sección</p>

Demostración visual

Calle 45 # 12-30
Bogotá, Colombia

Nueva sección

Buenas prácticas

  • No usar <br> para crear espacio visual — usar CSS margin.
  • <hr> indica cambio temático, no solo decoración.
