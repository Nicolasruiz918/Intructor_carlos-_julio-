Etiquetas de Formularios

<form> <label> <input>

Definiciones

<form> — Contenedor de todos los controles. Define acción y método.
<label> — Etiqueta descriptiva asociada a un control (mejora accesibilidad).
<input> — Campo de entrada. Tipos: text, email, password, number, date, radio, checkbox, file, submit.

Sintaxis

<form action="/enviar" method="POST"> <label for="nombre">Nombre:</label> <input type="text" id="nombre" name="nombre" required> <input type="submit" value="Enviar"> </form>

Buenas prácticas

  • Siempre asociar <label> con for + id.
  • Usar required, min, max para validación nativa.
  • Especificar el type correcto en cada <input>.
<textarea> <select> <fieldset> <legend> <button>

Definiciones

<textarea> — Campo de texto multilínea.
<select> + <option> — Lista desplegable de opciones.
<fieldset> — Agrupa controles relacionados.
<legend> — Título del fieldset.
<button> — Botón más versátil que input[type=submit].

Sintaxis

<fieldset> <legend>Preferencias</legend> <select name="nivel"> <option value="basico">Básico</option> <option value="medio">Medio</option> </select> <textarea rows="4"></textarea> <button type="submit">Enviar</button> </fieldset>

Buenas prácticas

  • Usar <button type="button"> dentro de forms para evitar envíos accidentales.
  • <fieldset> mejora la accesibilidad en grupos de radio/checkbox.
