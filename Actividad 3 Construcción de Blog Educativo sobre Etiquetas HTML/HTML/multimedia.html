Etiquetas de Multimedia

<img>

Definición

Incrusta una imagen en el documento. Es una etiqueta vacía (sin cierre). El atributo alt es obligatorio para accesibilidad.

Sintaxis

<img src="foto.jpg" alt="Descripción de la imagen" width="400" height="300" loading="lazy" >

Demostración visual

alt="Logo oficial del Servicio Nacional de Aprendizaje - SENA"

Buenas prácticas

  • Siempre incluir alt descriptivo.
  • Especificar width y height para evitar layout shifts.
  • Usar loading="lazy" para imágenes debajo del fold.
<audio> <video> <source>

Definiciones

<audio> — Incrusta audio con controles nativos del navegador.
<video> — Incrusta video con controles nativos.
<source> — Define fuentes alternativas para audio/video.

Sintaxis

<audio controls> <source src="musica.mp3" type="audio/mpeg"> </audio> <video controls width="640" poster="thumb.jpg"> <source src="video.mp4" type="video/mp4"> </video>

Demostración visual

Buenas prácticas

  • Proveer múltiples <source> para compatibilidad.
  • Usar poster en video para la miniatura inicial.
  • Evitar autoplay sin muted — los navegadores lo bloquean.
<iframe>

Definición

Incrusta un documento HTML externo dentro del actual. Se usa para mapas, videos de YouTube, widgets externos, etc.

Sintaxis

<iframe src="https://www.youtube.com/embed/VIDEO_ID" width="600" height="400" title="Título del video" loading="lazy" allowfullscreen ></iframe>

Demostración visual

Video: Curso HTML completo para principiantes — YouTube

Buenas prácticas

  • Siempre incluir atributo title para accesibilidad.
  • Usar sandbox para restringir permisos del contenido incrustado.
  • Evitar incrustar páginas de terceros no confiables.
